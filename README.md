# আমার হিসাব (Hisab)

অ্যান্ড্রয়েডের জন্য পার্সোনাল আয়-ব্যয় ও দেনা-পাওনার হিসাবের অ্যাপ।
**Kotlin + Jetpack Compose (Material 3)**। সব ডেটা ফোনেই SQLite-এ থাকে, ইন্টারনেট লাগে না।

---

## ১. নেভিগেশন গাইড (শর্টকাট)

অ্যাপের নিচে ৪টি ট্যাব আছে:

| ট্যাব | কী দেখা যায় | দ্রুত কাজ |
|---|---|---|
| **ড্যাশবোর্ড** | ক্যাশ, মোট লোন, মোট পাওনা, দোকান বাকি, ডিপিএস, জমি/সম্পদ, এই মাসের খরচ | যেকোনো কার্ডে ট্যাপ করলে বিস্তারিত তালিকা খোলে (শুধু দেখা যায়, এডিট করা যায় না) |
| **লেনদেন** | সব আয়-ব্যয়ের তালিকা | নিচের **＋ নতুন লেনদেন** বাটন, উপরে **⇄** ট্রান্সফার, **ফিল্টার আইকন** দিয়ে খাত অনুযায়ী দেখা, লেনদেনের পাশে **ডাস্টবিন** আইকন দিয়ে মোছা |
| **দেনা-পাওনা** | ৩টি উপ-ট্যাব: লোন নেওয়া / ধার দেওয়া / দোকান বাকি | **＋** বাটনে নতুন হিসাব, তালিকার যেকোনো নামে ট্যাপ করে পরিশোধ বা ফেরত নেওয়া |
| **অ্যাকাউন্ট** | ক্যাশ, বিকাশ, নগদ, ব্যাংক, ডিপিএস, জমি (প্রতিটির আলাদা আইকন) | **＋** বাটনে নতুন অ্যাকাউন্ট; অ্যাকাউন্টে ট্যাপ করে নাম বদল বা মোছা |

## ২. ব্যবহারের ধাপ

1. **অ্যাকাউন্ট ঠিক করুন:** অ্যাকাউন্ট ট্যাবে আপনার বর্তমান ব্যালেন্স দিন। নতুন অ্যাকাউন্ট যোগ করার সময় "শুরুর ব্যালেন্স" লিখুন।
2. **আয়/খরচ লিখুন:** লেনদেন ট্যাব → **নতুন লেনদেন** → খরচ বা আয় বেছে নিন → পরিমাণ, খাত লিখুন → **কোন অ্যাকাউন্ট থেকে কাটবে/জমা হবে** সিলেক্ট করুন (বাধ্যতামূলক) → সংরক্ষণ।
3. **ট্রান্সফার:** লেনদেন ট্যাবের উপরের **⇄** আইকন। যেমন ব্যাংক থেকে ডিপিএসে টাকা সরানো। এটা খরচ হিসেবে ধরা হয় না।
4. **লোন নেওয়া:** দেনা-পাওনা → লোন নেওয়া → **＋** → নাম, পরিমাণ ও যে অ্যাকাউন্টে টাকা জমা হলো সেটা দিন। পরিশোধের সময় তালিকায় নামে ট্যাপ করুন।
5. **ধার দেওয়া:** একইভাবে। টাকা যে অ্যাকাউন্ট থেকে গেল সেটা সিলেক্ট করুন। ফেরত পেলে নামে ট্যাপ করে অ্যাকাউন্ট সিলেক্ট করুন।
6. **দোকান বাকি:** দোকানের নাম ও বাকির পরিমাণ লিখুন। পরিশোধের সময় যে অ্যাকাউন্ট থেকে টাকা দিচ্ছেন সেটা সিলেক্ট করুন।
7. **ক্যাশ ইন হ্যান্ড** = ক্যাশ + বিকাশ/নগদ + ব্যাংক অ্যাকাউন্টের মোট ব্যালেন্স। ডিপিএস ও জমি আলাদা কার্ডে দেখানো হয়।

> ভুল লেনদেন মুছলে অ্যাকাউন্টের ব্যালেন্স আপনাআপনি ঠিক হয়ে যায়। ট্রান্সফার মুছলে দুই অ্যাকাউন্টেই ঠিক হয়।

8. **নাম সাজেশন:** দেনা-পাওনায় নতুন হিসাব যোগ করার সময় আগে সেভ করা নাম (যাকে ধার দিয়েছেন, যার কাছ থেকে লোন নিয়েছেন, দোকানের নাম) নিচে চিপ হিসেবে আসে। ট্যাপ করলেই নাম বসে যায়।
9. **অ্যাকাউন্ট এডিট:** অ্যাকাউন্ট ট্যাবে কোনো অ্যাকাউন্টে ট্যাপ করলে নাম ও আইকন বদলানো বা অ্যাকাউন্ট মোছা যায়। যে অ্যাকাউন্টে লেনদেন আছে সেটা মোছা যায় না, যাতে অন্য হিসাব এলোমেলো না হয়। আগে ওই লেনদেনগুলো মুছুন।

### অ্যাকাউন্টের লোগো/আইকন
- লোগো না দিলে প্রতিটি অ্যাকাউন্টে আলাদা আইকন ও রং দেখায়। অ্যাকাউন্টে ট্যাপ করে আইকন বদলানো যায়।
- নিজের লোগো দিতে চাইলে PNG ফাইল `app/src/main/res/drawable-nodpi/` ফোল্ডারে (না থাকলে বানিয়ে) নিচের নামে রাখুন। অ্যাপ নিজেই খুঁজে নেবে:

| ফাইলের নাম | কোন অ্যাকাউন্টে বসবে |
|---|---|
| `acc_bkash.png` | বিকাশ |
| `acc_nagad.png` | নগদ |
| `acc_ab_bank.png` | AB Bank |
| `acc_tfic.png` | TFIC Bank |
| `acc_type_bank.png` | সব ব্যাংক অ্যাকাউন্ট (আলাদা লোগো না থাকলে) |
| `acc_id_<নম্বর>.png` | নির্দিষ্ট একটি অ্যাকাউন্ট (আইডি নম্বর অনুযায়ী) |

> ফাইলের নামে শুধু ইংরেজি ছোট হাতের অক্ষর, সংখ্যা ও `_` চলবে। লোগোগুলো সংশ্লিষ্ট প্রতিষ্ঠানের নিজস্ব সম্পদ, তাই তাদের অফিশিয়াল সাইট বা অ্যাপ থেকে নিজে সংগ্রহ করুন।

## ৩. GitHub Actions দিয়ে APK বানানো

1. পুরো প্রজেক্ট GitHub রিপোতে `main` ব্রাঞ্চে পুশ করুন।
2. পুশ করলেই **Actions → Build Release APK** স্বয়ংক্রিয়ভাবে চলবে। হাতে চালাতে চাইলে **Run workflow** চাপুন।
3. শেষ হলে রিপোর ডানপাশের **Releases** থেকে সরাসরি `hisab-vX.Y.apk` নামিয়ে নিন। চাইলে রানের পাতার **Artifacts** থেকেও পাবেন।

### ভার্সন নিয়ম
- **versionCode** = রান নম্বর (প্রথম বিল্ডে `1`, তারপর `2`, `3`...)
- **versionName** = `1.<রান নম্বর>` (যেমন `1.1`, `1.2`, `1.3`...)
- মেজর ভার্সন বদলাতে `.github/workflows/build.yml`-এর `MAJOR_VERSION` বদলান।

### স্থায়ী সাইনিং কীস্টোর (আপডেট ইনস্টল করতে জরুরি)
কীস্টোর না দিলে প্রতিবার নতুন অস্থায়ী কী দিয়ে সাইন হয়, ফলে আগের অ্যাপের উপর আপডেট ইনস্টল হবে না। একবার এটা বানিয়ে নিন:

```bash
keytool -genkeypair -v -keystore release.jks -alias hisab \
  -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 release.jks     # macOS: base64 -i release.jks
```

তারপর রিপোর **Settings → Secrets and variables → Actions** এ এই ৪টি Secret যোগ করুন:

| Secret | মান |
|---|---|
| `KEYSTORE_BASE64` | উপরের `base64` কমান্ডের আউটপুট |
| `KEYSTORE_PASSWORD` | কীস্টোরের পাসওয়ার্ড |
| `KEY_ALIAS` | `hisab` |
| `KEY_PASSWORD` | কী-এর পাসওয়ার্ড |

> ⚠️ `release.jks` ফাইল ও পাসওয়ার্ড নিরাপদ জায়গায় ব্যাকআপ রাখুন। হারালে একই অ্যাপের আপডেট দেওয়া যাবে না। এই ফাইল রিপোতে আপলোড করবেন না (`.gitignore` এ বাদ দেওয়া আছে)।

## ৪. টেকনিক্যাল তথ্য

- Release মোডে বিল্ড (`assembleRelease`)
- R8 চালু: `isMinifyEnabled = true`, `isShrinkResources = true` (APK ছোট হয় ও কোড অবফাস্কেট হয়)
- minSdk 26 (Android 8.0), targetSdk 34
- লোকালি বিল্ড করতে (Gradle 8.9 ও JDK 17 লাগবে): `gradle assembleRelease`
- আউটপুট: `app/build/outputs/apk/release/`
