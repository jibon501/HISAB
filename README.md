# আমার হিসাব (Hisab)

অ্যান্ড্রয়েডের জন্য পার্সোনাল আয়-ব্যয় ও দেনা-পাওনার হিসাবের অ্যাপ।


## নেভিগেশন (নিচের ট্যাব)
- **ড্যাশবোর্ড** — সারসংক্ষেপ কার্ড (ক্যাশ, ধার দেওয়া, ধার নেওয়া ইত্যাদি)। কার্ডে চাপলে তালিকা, তালিকার নামে চাপলে ধার-হিসাব দেখা যায় (শুধু দেখার জন্য)
- **লেনদেন** — আয়-ব্যয়ের তালিকা। সারির নামে (খাত/তারিখের অংশে) চাপলে **তারিখ ও টাকার পরিমাণ এডিট** করা যায়
- **দিছি** — যাদের আমি ধার দিয়েছি তাদের তালিকা
- **নিছি** — যাদের কাছ থেকে আমি ধার নিয়েছি তাদের তালিকা

## ব্যবহার: ধারের হিসাব (দিছি / নিছি ট্যাব)
1. তালিকার কোনো নামে চাপুন — হিসাবের টেবিল খুলবে
2. নিচের বাটন: **+** (ফেরত যোগ), **শেয়ার**, **মুছুন**
3. **+** চাপলে পুরো স্ক্রিনের ফর্ম আসে: নাম বদল ও ফেরতের অ্যাকাউন্ট/টাকা দিন, তারপর **সংরক্ষণ** (বা **বাতিল**)
4. ফেরতের লেবেল: দিছি-তে "ফেরত দিছি", নিছি-তে "ফেরত নিয়েছি"

## নতুন ফিচার / আপডেট
- ধারের লেখা বদল: ট্যাব, ফর্ম ও হিসাবের লেবেলে "দিছি" / "নিছি"; শুধু ড্যাশবোর্ডের কার্ডে "ধার দেওয়া" / "ধার নেওয়া"
- ড্যাশবোর্ডের ধার-হিসাব থেকে "গ্যালারিতে সেভ" ও "শেয়ার" বাদ
- লেনদেন ট্যাবে নামে চাপলে তারিখ ও টাকার পরিমাণ এডিট
- দিছি/নিছি ট্যাবে "সম্পাদনা"-র বদলে "+" (পুরো স্ক্রিনের ফর্ম, নিচে সংরক্ষণ/বাতিল), সাথে শেয়ার ও মুছুন বাটন
